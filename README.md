# Tumblr Downloader (Eagle Plugin)

一款专为 Eagle 设计的 Tumblr 下载器，用于下载指定的 Tumblr Blog。

## ✨ 核心特性
- 👥 **多维仪表盘**：支持关注列表多选，活跃与归档一键分类。
- 🔄 **秒级增量追更**：智能记录上次下载断点，只抓取最新更新，拒绝重复。
- ⚡ **静默导入**：配合 Eagle 的偏好设置（自动跳过），下载全自动无弹窗打断。
- ⚙️ **独立凭证管理**：API Key 本地安全隔离存储。

## 🔧 安装方法
1. 下载本仓库的 `.isp` 插件包。
2. 双击 `.isp` 文件，或者直接拖入 Eagle 软件中即可完成安装。
