# Tumblr Downloader (Eagle Plugin)

一款专为 Eagle 设计的 Tumblr 下载器，用于下载指定的 Tumblr Blog。

## 核心特性

- 下载指定的 Tumblr Blog（支持用户名或 url）；
- 可以限定内容的发布时间，比如只下载 2026/01/01 之后的帖子；
- 首次添加 Blog 并下载之后，支持批量下载。
- 列表中的 Blog 可以删除或归档。

## 安装方法

1. 下载本仓库的 `.isp` 插件包。
2. 双击 `.isp` 文件，或者直接拖入 Eagle 软件中即可完成安装。
3. 请自行申请 Tumblr 的 [API Key](https://www.tumblr.com/oauth/apps)，在「设置」页面中填入。
